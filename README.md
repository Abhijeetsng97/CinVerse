## //CinVerse - Movie Database//
A modern, responsive **Movie Database Web Application** that allows users to discover, search, and see ratings for popular movies and TV shows. This project fetches real-time media data to provide up-to-date information on trending titles, user ratings and summaries.

## Features
- **Quick Search:** Quickly find movies or TV shows
- **Real-time Data Trends:** View curated lists of currently trending movies on homepage
- **Fully Responsive Design:** Clean UI optimized for seamless browsing across desktops, tablets, and mobile devices.
- **Dark Mode:** Easy-on-the-eyes dark theme built natively for nighttime browsing.



## Tech Stack
- HTML & CSS 
- JavaScript React.js 
- Tailwind CSS 
- [The Movie Database (TMDb) API](https://themoviedb.org)



## To run this locally
Follow these simple steps to set up and run the project locally:

         1. **Prerequisites**
               You will need an API key from your media provider. 
               1. Sign up or log into [TMDb](https://themoviedb.org).
               2. Navigate to your account settings to request an **API Key** for [TMDb](https://developer.themoviedb.org/reference/discover-movie)

         2. **Clone the repository**

         3. **Configure Environment Variables:**
               Create a `.env` file in the root directory and add your API key:
               ```env
               VITE_TMDB_API_KEY=your_api_key_here
               ```

         4. **Install Dependencies:**
               ```bash
               npm i use
               ```

         5. **Run the local development server:**
               ```bash
               npm run dev
               ```

         6. Open your browser and navigate to the local port provided in your terminal.
